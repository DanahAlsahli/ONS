# ONS — Pilgrim Assistance Platform

**ONS (أُنس) — A Smart Platform for Assisting Lost Hajj and Umrah Pilgrims**

ONS is a technology-driven project focused on supporting the identification and assistance of lost Hajj and Umrah pilgrims.

## Project Overview

During Hajj and Umrah seasons, pilgrims may become separated from their groups or need help reaching the appropriate support personnel.

ONS aims to support the handling of these situations through digital identification workflows, assistance reporting, and location-related functionality.

## Key Features

- **Pilgrim Identification:** Supports workflows related to identifying and verifying pilgrim information.
- **QR and OCR Processing:** Supports documented QR-based identification and optical character recognition workflows.
- **Assistance Reports:** Supports reporting and handling assistance cases.
- **Maps and Routes:** Provides map- and route-related functionality.
- **Field Staff Support:** Includes functionality associated with authorized staff and field personnel.
- **Notifications:** Supports notification-related operations.
- **Authentication and Access Control:** Provides user authentication and access-management functionality.

> Feature availability and behavior depend on the current implementation in the codebase.
